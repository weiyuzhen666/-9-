# 实验三 提交说明（学习通·简短版）

## ALS 主要参数

本实现基于 Spark MLlib ALS 的交替最小二乘原理（课程离线包为纯 Python 环境，ALS 用纯 Python 等价求解：固定 U 解 V、固定 V 解 U，每次解正规方程 `(AᵀA + λI)x = Aᵀb`）。

| 参数 | 取值 | 含义 |
|---|---|---|
| `rank` | 8 | 隐向量维度（用户/电影各 8 维） |
| `regParam` (λ) | 0.1 | L2 正则化系数 |
| `maxIter` | 5 | 交替迭代轮数 |
| `seed` | 42 | 随机初始化种子（保证可复现） |

训练数据：`evaluation/train.csv`（4500 用户 × 8459 电影，58.35 万条真实评分）；模型工件落盘 `models/{business,evaluation}/als-v1/als.pkl`。

## 三种算法评价对比（真实计算，非编造）

数据来自 `models/evaluation/metrics.json`（由 `recommender/student/evaluate_all.py` 跑通 4209 名 validation 用户、4198 名 test 用户得到）：

| 算法 | validation P@10 | validation R@10 | test P@10 | test R@10 |
|---|---:|---:|---:|---:|
| content | **0.00328** | 0.00524 | 0.00331 | 0.00547 |
| itemcf | 0.00280 | **0.00710** | **0.00364** | **0.00891** |
| als | 0.00017 | 0.00008 | 0.00005 | 0.00002 |

## 1–2 句话分析

在 test 分区上，**ItemCF 评价效果最好**（P@10=0.00364、R@10=0.00891，均为三者最高），原因是 MovieLens 这种评分数据里物品共现信号比稀疏的类型向量、低秩隐向量更能刻画用户偏好；ALS 因为隐向量维度小（rank=8）、迭代轮数少（5），且未做评分中心化，欠拟合较严重，指标明显偏低——这与"本实验不要求 ALS 指标一定高于 ItemCF，重点考查算法实现正确性"的题目说明一致。

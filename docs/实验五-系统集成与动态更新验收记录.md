## 二、核心演示：行为驱动推荐动态更新（截图 2/3 对比）

**步骤 1 · 评分前**（`exp5_2_before_rating.png`）：零评分用户 `exp5demo` 的"为你推荐"返回热门经典 Top10：

Shawshank Redemption / Forrest Gump / Pulp Fiction / Matrix / Silence of the Lambs / Star Wars IV / Fight Club / LOTR / Schindler's List / Jurassic Park

（content 算法零评分 → 按 `train_support` 降级 Popular，符合"新用户采用 Cold Start 或 Popular 策略"）

**步骤 2 · 新增评分**（`exp5_3b_rating_action.png`）：在《Terminator 2》详情页打 **5.0 分**。

**步骤 3 · 评分后**（`exp5_3_after_rating.png`）：首页"为你推荐"完全更新为动作/科幻类：

Barb Wire / Star Trek V / Starship Troopers / King Kong vs. Godzilla / Beneath the Planet of the Apes / Battle for the Planet of the Apes / Conquest of the Planet of the Apes / Escape from the Planet of the Apes / Wing Commander / Superman II

**推荐依据核验**：T2 在 `content.pkl` 中预计算的 Top-K 内容邻居（737/1373/1676/2365/2530…）均为同类型动作科幻片；5 星评分 → 权重 `(5-2.5)/2.5 = +1.0`，其邻居的聚合相似度分跃升至榜首，因此推荐列表整体迁移到动作/科幻方向。前后列表 0 重合，直接证明**最新评分行为参与了推荐计算**。
